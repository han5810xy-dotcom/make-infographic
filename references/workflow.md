# 默认出图流程：一张图 = 一个转弯

默认只生成一张竖图，固定四块：**原以为 → 撞车 → 正解 → 一句带走**。旧版多图结构只用于历史回归，不作为新内容默认格式。

## 1. 完整归档

把选中文本或用户给的对话完整存成 `<工作目录>/.source.md`。不要先概括，不要补写原文没有的内容。原文太长时按一个完整转弯切段，不静默截断。

## 2. 找到转弯

先分别定位：

1. 原以为：对话开始时相信的那句话。
2. 撞车：哪个反例、代价或矛盾让它站不住。
3. 正解：改口之后采用的新判断。
4. 一句带走：离开这段对话后仍该记住的一句。

「原以为」与「正解」必须不同。四块都来自同一段对话，不把别处的金句拼进来。

## 3. 先做记忆自检

出图前回答：

> 一年后只看到这张图，能想起这次对话吗？

如果缺「原以为」「撞车」或「正解」，停止并说清缺哪一块。如果旧判断与新判断相同，也停止，不硬造转弯。

## 4. 运行默认入口

```bash
SKILL="$HOME/.qoder-cn/skills/make-infographic"
node "$SKILL/scripts/make.mjs" --in .source.md --out 主题
```

程序会自动：

- 先收集完整对话，再判定候选转弯；纯讲解不会硬凑成反转；
- 多个转弯分别出编号图，一张只讲一个转弯；
- 把旧版式或旧结构换成 turn card；
- 逐字核对旧判断；找不到原话时标为 `inferred`，画面显示「推断」；
- 超过 300 字时裁剪，并打印「未上图」清单；
- 在浏览器里测量溢出、字号、中文字体和内部字段名；
- 通过后才发布 PNG。

最后一行必须是 `OK`。

## 5. 人工复核

用 Read 打开 PNG，确认：

- 只有标题和四块，没有多余版式；
- 四块都非空，且确实形成转弯；
- 没有 `units`、`relations`、`coverage`、`差别`、`依据`、`归纳`；
- 没有省略号、截断或文字出框；
- 缩到 600px 宽仍能看清；
- 可见正文不超过 300 字。

程序通过只说明工程规则通过，不证明学习效果。

## 6. 保留完整资产

成功后在 `<工作目录>/infographics/` 保留：

- `<主题>.png`
- `<主题>.html`
- `<主题>.json`
- `<主题>.source.md`
- `index.html`

JSON 中有来源标记、未上图清单、记忆自检和浏览器 QA；原文与完整记录在，删掉 PNG 也能重出。相同内容使用稳定 id 覆盖，不重复积累。

## 7. 卡片库与复习

出图后可用 `scripts/library.mjs` 做本地关键词、日期、主题和状态筛选；时间线与主题视图位于 `.knowledge/cards/`。用 `--supersedes`、`--expands`、`--contradicts` 连接旧卡。

每张卡自动生成一个落在「正解」块的探针：

```bash
node scripts/review.mjs due
node scripts/review.mjs answer 卡片id "自己的答案"
node scripts/review.mjs confirm 卡片id
```

答对延长间隔，答错缩短；完整间隔为 1／3／7／21／60 天。块级诊断只是本地词面提示，不能代替学习者确认。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| 缺「原以为」 | 不出图，说明没有找到旧判断 |
| 缺「撞车」 | 不出图，说明没有找到反例、代价或矛盾 |
| 缺「正解」 | 不出图，说明没有找到改口后的新判断 |
| 超过 300 字 | 自动裁剪并打印「未上图」，不缩字 |
| 原话不逐字 | 旧判断标为 `inferred`，画面显示「推断」；其余归纳标记写入 JSON |
| 旧版式不匹配 | 自动换成 turn card |
| 没找到 Edge 或 Chrome | 设置 `BROWSER_PATH`，不自动下载 Chromium |
| 浏览器不可用 | 加 `--html-only`，明确标注「未实测」 |
