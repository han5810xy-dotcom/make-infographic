# 社交文案

## 1. 中文短版（V2EX / 即刻 / 小红书）

AI 记得每一次对话，你只记得住一张图。我把一段对话压成「原以为 → 撞车 → 正解 → 一句带走」，不是摘要，是记录你怎么想通的。纯前端可试，也能装进 Qoder。

配图：`assets/before-after.png`  
链接：https://github.com/han5810xy-dotcom/make-infographic

## 2. 英文版（X / Hacker News）

AI remembers every conversation; you remember one image. I built make-infographic to turn a dialogue into Before → Collision → Correction → Takeaway, with a zero-install web demo and a Qoder Skill.

GIF: `assets/demo.gif`  
Link: https://github.com/han5810xy-dotcom/make-infographic

## 3. 中文发布帖（GitHub / 博客 / 社区长帖）

做这个项目，是因为我总在三天后忘记一段对话到底改变了我什么。于是我把聊天记录收成一张四块转弯图：原来相信什么、被什么撞翻、最后改成什么、带走哪一句。它不调模型，不上传文本；网页版可以直接粘贴出图，Qoder 版选中对话说「出图」即可。项目、三个真实示例和安装包都在这里。

配图：`assets/demo.gif` 或 `assets/social-preview.png`  
链接：https://github.com/han5810xy-dotcom/make-infographic
